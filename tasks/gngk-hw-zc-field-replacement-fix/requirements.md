# Requirements: 国内公开货物自筹字段替换修复

## 来源

- 生成自当前对话中的需求对齐内容。
- 关联 PRD：`prd.md`

## 原始对齐需求

# 国内公开货物自筹字段替换修复 业务 PRD 对齐稿

## 目标

- 国内公开货物自筹生成时，能从模板中正确识别并替换采购人、预算金额、项目联系人等字段，且移除不属于该类型的历史特殊字段。

## 范围

### 包含

- 修复 `buyer_name` 的提取与替换口径。
- 新增 `investment` 的提取与替换口径。
- 修复 `project_zbr_xbr` 的提取与替换口径。
- 移除 `project_content_v1`、`similar_project_performance_date` 两个不属于国内公开货物自筹的特殊字段。

### 不包含

- 不新增招标类型。
- 不改变最高限价为独立字段。
- 不改变现有正文全局替换机制。
- 不依赖真实接口做验证。

## 业务场景

### 场景1：采购人名称替换

- 模板中可能出现 `采购人：xxx` 或 `招标人：xxx`。
- 一份文档中两者不会同时出现，命中任一种即可作为 `buyer_name` 的旧值来源。
- 图一中的 `复旦大学附属中山医院` 应能被新的采购人名称替换。

### 场景2：预算金额替换

- 只从 `预算金额：450 万元（人民币）` 中提取数字 `450` 作为 `investment` 的旧值来源。
- 不从“最高限价”反向提取。
- 提取到旧数字后，沿用现有替换行为：正文中相同旧数字统一替换，因此“最高限价”里的相同金额也会同步变化。
- 新值格式：`140.0` 显示为 `140`；小数部分有有效数字时保留有效小数。

### 场景3：项目联系人替换

- `project_zbr_xbr` 兼容 `项目联系人：xxx` 和 `联系人：xxx`。
- 只提取姓名部分，到下一行 `电话`、`电 话`、`传真`、`邮箱` 等联系方式标签前停止。
- 图三中的 `史倩倩、刘宇昂` 应能被替换，不把电话内容拼入字段。

### 场景4：移除错误特殊字段

- 国内公开货物自筹不再提取或替换 `project_content_v1`。
- 国内公开货物自筹不再提取或替换 `similar_project_performance_date`。
- 这两个字段不应再出现在该类型的替换字段列表或替换结果中。

## 验收口径

- 使用模拟数据即可验证，不需要调用真实接口。
- 替换结果能包含 `buyer_name`、`investment`、`project_zbr_xbr` 对应替换对。
- `investment` 只从“预算金额”行取旧数字，但替换时正文相同旧数字按现有机制统一替换。
- `采购人/招标人`、`项目联系人/联系人` 两类模板写法均可正常提取。
- 替换字段列表中不再出现 `project_content_v1` 和 `similar_project_performance_date`。
