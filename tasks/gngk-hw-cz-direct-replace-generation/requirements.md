# Requirements: 国内公开货物财政无保护字段模板生成

## 来源

- 生成自当前对话中的需求对齐内容。
- 关联 PRD：`prd.md`

## 原始对齐需求

本轮需要支持现有“国内公开 + 货物 + 财政”首次生成链路，让它可以使用无保护字段模板完成招标文件生成。

这不是新增前端大类，也不是新增一个全新的表单入口；用户仍然在现有国内公开页面中选择“货物 + 财政”。后端运行态仍是 `gngk_hw_cz_tender` / `gngk_hw_cz`。

用户提供的测试材料位于：

- `C:\Users\0325\Desktop\投标文件测试用例\国内公开货物财政测试用例集\测试用例1`
- 模板文件：`254226-小动物活体光声显微成像设备-招标文件-初稿1（审2）.doc`
- 参数文件：`技术参数.docx`

## 范围

### 包含

- 支持“国内公开 + 货物 + 财政”的首次生成闭环。
- 任务创建、队列执行、SSE 进度、生成完成和下载结果保持正常。
- 生成模式默认仍为模板优先，不改成参数优先。
- 清空“第四章 招标需求”和“第五章 评标方法与程序”之间的旧正文，并将 AI 生成正文插入到“第四章 招标需求”标题下方。
- 继续支持现有样式回填能力，并沿用现有安全门禁。
- 相关代码事实和长期知识需要同步到 `asset/` 知识包。

### 不包含

- 本轮不支持 rewrite / edit 聊天修改链路的财政货物直替换分发。
- 不新增前端招标类型或新的前端页面。
- 不改变国内公开货物自筹、服务自筹、服务财政、询价采购、国际公开等其它类型的生成行为。
- 不把 Word 受限编辑时显示的黄色可编辑区域当成正文高亮样式生成或继承。
- 不要求生成结果恢复模板原来的限制编辑状态。

## 业务场景

### 场景 1：选择国内公开货物财政生成文件

- 用户在国内公开页面选择“货物 + 财政”。
- 用户上传或选择财政货物模板文件和技术参数文件后发起生成。
- 系统仍按模板优先生成：模板内容用于参考生成风格、章节结构和措辞，技术参数作为本次项目材料参与生成。

### 场景 2：清空并重写招标需求正文

- 系统保留“第四章 招标需求”和“第五章 评标方法与程序”两个章节锚点。
- 系统清空两个锚点之间的原“招标需求”正文。
- 系统不再要求保留或识别 `交付日期`、`付款方式` 等受保护字段行。
- AI 生成后的完整正文插入到“第四章 招标需求”标题下方。
- “第五章 评标方法与程序”及其后续内容不能被误删或覆盖。

### 场景 3：样式与模板限制

- 生成正文继续支持样式回填。
- 样式回填沿用现有安全门禁，不能因为该类型改为整段替换而跳过样式回填摘要或安全策略。
- 模板中可编辑区域的黄色显示不是业务正文样式，也不作为需要继承的高亮效果。
- 如果节点内部按现有 gjgk / common 节点方式尝试处理文档保护，可以保持一致；业务验收只要求该模板可编辑区域能够正常清空和写入。

## 验收口径

- 国内公开“货物 + 财政”可用给定模板和技术参数完成首次生成。
- 生成任务能够正常进入队列、推送进度、完成并提供下载结果。
- 生成结果中“第四章 招标需求”下方正文由新内容替换，未残留旧模板正文。
- “第五章 评标方法与程序”及其后续内容不被误删或覆盖。
- 生成结果不因缺少 `交付日期`、`付款方式` 等受保护字段而失败。
- 样式回填仍可生效，并在任务 state / 结果摘要中保留现有样式回填信息。
- 黄色可编辑提示不作为正文高亮样式要求。
