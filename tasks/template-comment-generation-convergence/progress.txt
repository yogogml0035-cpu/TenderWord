## Codebase Patterns
- `TenderFormShared` is the shared source of truth for upload labels, draft sync, and submit validation; wrapper forms should only supply tender-type defaults.
- `chatStore.mergeConversationDraft()` is the normalization point for `ConversationFormDraft.files`; keep only populated upload slots and let the form own draft writes.
- Playwright validation can seed `chat-storage` directly and mock `/api/conversations/*/heartbeat` to reach `/tender` without backend or Word COM.
- Generate payloads now use `file_paths.template` + `file_paths.tender_params` only; edit uploads use `FileType` `edit_source` rather than generate upload slots.
- Backend generate requests now validate `file_paths` through `GenerateFilePaths`; `DocumentService._build_initial_state()` maps only `template_path` and `tender_param_paths` for generate tasks.
- Generate Word nodes now consume `state.template_path` directly: `prepare_template` copies it to `prepared_doc_path`, and `extract_tender_params` extracts template reference text from it while joining `tender_param_paths`.
- Standard generate graphs now split comments by `generation_mode`: workflow always runs `generate_comments` before `update_word`; agent skips `generate_comments` and runs `comment_agent` after `update_word`, while total-node estimates ignore `origin_tender_path`.
- Prompt builders should expose the smallest contract needed by the current node; `generate_comments` now forwards only `tender_type` and `polished_text`, and legacy plan fields should be treated as inert state if they still appear in fixtures.
- `comment_agent` autonomous generation reuses `render_comment_prompt()` for both agent generate and comment_supplement; do not reintroduce separate `comment_no_reference` prompt modules or exports.
- Template candidate selection is single-file and all-or-nothing: backend returns `selected_file`, frontend fills only `files.template`, and failures surface as `TEMPLATE_SELECT_FAILED` without `partial_success`.
- 旧生成/批注契约清理要同时做 active-path `rg` 回归搜索；嵌套运行时 `prompts_log` 应被 `.gitignore` 排除，避免历史日志污染字段搜索结果。
